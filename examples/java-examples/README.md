# Java Examples

This directory contains Java-specific examples for using remediation libraries.

## Available Examples

- **log4j-remediation/**: Example of upgrading Log4j to address security vulnerabilities
- **dependency-updates/**: Examples of updating vulnerable dependencies
- **security-patches/**: Examples of applying security patches

## Structure

Each example follows this structure:
```
example-name/
├── README.md           # Detailed explanation and instructions
├── before/            # Code before remediation
├── after/             # Code after remediation
├── libraries/         # Required libraries for this example
└── documentation/     # Additional documentation
```

## Running Examples

1. Navigate to the specific example directory
2. Read the README.md for prerequisites and instructions
3. Follow the step-by-step guide provided
4. Verify the remediation was successful
