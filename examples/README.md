# Examples

This directory contains practical examples of how to use the libraries in this repository for common remediation scenarios.

## Structure

Examples are organized by language and use case:

```
examples/
├── java-examples/            # Java remediation examples
├── python-examples/          # Python remediation examples
├── javascript-examples/      # JavaScript remediation examples
├── dotnet-examples/          # .NET remediation examples
└── general-examples/         # Cross-platform examples
```

## Usage

Each example includes:
- Source code demonstrating library usage
- Documentation explaining the remediation scenario
- Step-by-step instructions
- Expected outcomes and verification steps

## Contributing Examples

When adding new examples:
1. Create a descriptive directory name
2. Include complete, working code
3. Add comprehensive documentation
4. Test the example thoroughly before committing
