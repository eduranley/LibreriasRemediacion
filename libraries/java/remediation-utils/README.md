# Java Remediation Utils

This directory contains general-purpose Java utility libraries for common remediation tasks.

## Contents

Place JAR files and related documentation for utility libraries here.

## Usage

1. Add your utility JAR files to this directory
2. Include a README.md for each library explaining its purpose and usage
3. Provide Maven/Gradle dependency information when available

## Example Structure

```
remediation-utils/
├── README.md                    # This file
├── string-sanitizer-1.0.jar    # Example utility library
├── string-sanitizer-README.md  # Documentation for the library
└── maven-dependency.xml        # Maven dependency snippet
```
